# GP 訓練資料交接檢查（2026-11-06）

本文件記錄既有資料的唯讀驗收，供模型訓練負責人使用；不代表正式 IMF 推論已完成。

## 資料清點

- `petar_m45_training_grid.csv`：430 列，run ID 各對應一個資料目錄。
- `results/nbody_training_runs/<run_id>/`：430 個目錄，每個都有非缺失的 `observed.stats.json` 與 `observed.provenance.json`。
- 以 GP 的六個輸入參數（`n_systems`、`binary_system_fraction`、`half_mass_radius_pc`、`mcluster_S`、`imf_alpha_high`、`imf_alpha_low`）分組：350 組不同參數，其中 330 組各一筆，20 組各五筆。後者是不同種子的重複模擬。
- 來源紀錄依既有程式使用的路徑標記分為修補版 PeTar 335 筆、原版 95 筆；這種路徑分類仍須以執行檔版本或雜湊核實。

## 初步交叉驗證

既有 `scripts/nbody_petar/emulator_holdout_check.py` 的五折隨機切分，在 430 筆上各統計量 R² 的中位數約 0.857；只取修補版 335 筆約 0.835，只取原版 95 筆約 0.856。全資料的五個雙星比例統計量 R² 均為負值。這些值只是資料可用性的初篩，不是正式推論品質保證。

同參數的五次重複可能跨越目前的訓練與測試折，形成資訊洩漏。下一輪驗證應以六參數組合作為分組單位，讓同組所有種子同時落在同一折；並分別報告修補版、原版及混合資料結果。若分組後星數、密度或斜率的預測誤差顯著上升，應以分組結果為準。

目前不應把雙星比例輸出用於正式 MCMC 約束，也不應因這份初篩結果宣稱已得到 IMF 後驗。正式推論還需要觀測與模擬定義對齊、預測誤差傳遞、先驗及後驗檢查。
