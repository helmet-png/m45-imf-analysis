# M45 BP15 候選的樣本規模有多大？

日期：2026-08-22  
狀態：**完成假設性計數；不是成員判定或 IMF 結果**

## 已保存的現有樣本

`cmd_members.csv` 共有 1,078 顆星。依已保存 Step 5 質量映射分箱：

| 質量範圍 | 現有星數 |
|---|---:|
| `<0.3 M☉` | 370 |
| `0.3–0.5 M☉` | 279 |
| `≥0.5 M☉` | 429 |

另外，`G=16–18` 的現有 CMD 樣本有 459 顆。

## 如果 16 顆都被接受

這只是一個「全部都是真成員」的上限式記帳情境：

- 相對整個 CMD 樣本增加 1.48%；
- 相對 `<0.3 M☉` 樣本增加 4.32%；
- 相對 `G=16–18` 樣本增加 3.49%；
- 對 `≥0.5 M☉` 的 alpha 直接質量段增加 0 顆。

因此，BP15 不太可能靠「多 16 顆」直接改寫高質量段計數；它比較可能影響
低質量完整性、暗端 CMD 形狀與 nuisance 參數。4.3% 的低質量樣本規模也不是
完全可忽略，但在完整場與控制場尚未重建前，不能把它解釋成真實缺失比例。

## 尚未驗證

- 16 顆是否全是真成員；
- 放寬門檻後會新增多少背景污染；
- selection 修正後的淨增加是否仍接近 16 顆；
- 間接參數耦合會讓 alpha 移動多少。

## 決策

這個規模足以支持一次 selection-function smoking test，但不足以跳過 selection
驗證直接重跑正式前向模型。下一步仍是完整星團場與控制場的 BP15 重建，並先
通過整體、星等分箱及 `G≥17` 紅／藍驗證。
