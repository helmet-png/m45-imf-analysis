## 三、f_bin 定義換算（第二節 #6 的計算）

用 headline 10 次重複的 (f_bin, γ) 逐次換算，p(q)∝q^γ、q∈[0.10, 1]：

f(q>q_c) = f_bin × (1 − q_c^(γ+1)) / (1 − 0.10^(γ+1))

| 只數 q > | 換算後雙星比例 |
|---|---|
| 0.10（本專案原定義） | 0.568 ± 0.023 |
| 0.2 | 0.410 ± 0.019 |
| 0.3 | 0.313 ± 0.021 |
| 0.4 | 0.242 ± 0.021 |
| 0.5 | 0.185 ± 0.018 |
| 0.6 | 0.138 ± 0.015 |
| 0.7 | 0.097 ± 0.012 |

**訂正（同日，查過 Liu+2025 原文摘要後）**：初版這裡寫「q>0.4–0.5 跟
Hobart 吻合」，前提是文獻只數 q>0.4–0.5，這個前提沒查證。實際查到：
Liu, Shao & Li (2025, AJ 169, 116, arXiv:2501.01617) 的 0.34±0.02 數到
隨主星質量變化的偵測下限 q_lim，幾乎涵蓋全部 q，而且他們量到 q<0.3
有明顯不足；Hobart+2026 的 q 定義仍沒查到原文。

初步判讀（改寫後）：q<0.3 佔我們全部雙星的 44.8%，這段 CMD 幾乎量不到，
份量主要來自 q_gamma 的冪律外推。在兩邊都量得到的 q>0.3，我們是
0.313±0.021，跟 Liu+2025 約差 1σ。分歧不在「總雙星比例」，而在 q<0.3
的分布形狀（我們外推出很多、Liu 量到不足）。γ 的注入回收偏差
−0.12～−0.18（偏負，會高估低 q 端）還沒傳播進換算。正式記錄見
`LIMITATIONS.md` D24。

## 四、要不要統一？

判準：差異是**慣例或定義**（同一個物理量，用不同單位、零點或計數規則），
就該統一，統一後誤差預算不會少掉任何真資訊。差異是**物理模型的選擇**
（不同的恆星演化、大氣、對流處理），就**不該**統一，因為那個差異本身就是
要量的系統誤差；硬統一等於把誤差藏起來。

| 項目 | 建議 | 理由 | 成本 |
|---|---|---|---|
| #1 N-body 的 Z | **先量再決定**：網格 CSV 加選填欄位，舊網格照舊 0.02，另跑 3 組 Z=0.0144 中央 seed | 初版寫「正式網格還沒跑」是錯的：10 組正式網格與 430 組訓練網格都已用 0.02 跑完；而且該對齊絕對 Z 還是相對太陽值沒有定論 | 3 組各約 17 分鐘 |
| #4 消光係數 | **統一**改成 Gaia 官方的顏色相依係數，所有等時線都套同一套 | 定義差，而且可能是 A_V 偏高的成因 | 中：要改 `_Ext`，headline 要重跑 |
| #5 雙星配對 | **記錄並量化**：bridge 已有 primary 定義、`observe_snapshot.py` 已存在（初版說不存在是錯的）；真正的差在「主星 MF → 成員星 IMF」靜態換算量：前向規則 +0.030、PeTar t=0 +0.186 | Δα 是同定義的時間差，不受影響；換算量差約 0.16 | Δα 對配對的敏感度要自己產初始條件，留待決定 |
| #6 f_bin 定義 | **統一**：論文同時報 q≥0.10 與 q>0.5 兩個數字 | 純定義差 | 低：第三節已算出 |
| #12 星團縱深 | **建模**，不是統一：把成員 DM 的散布（或逐星視差）放進合成星團 | 真實物理效應，目前被別的參數吸收 | 中 |

| #17 成員方法 | 不統一，維持 HR23 當對照 | 已量到敏感度≈0 | — |

**優先順序（初步判讀）**：
1. #6 f_bin 定義：零計算成本，而且直接改變論文裡一個「與文獻衝突」的敘述。
2. #1 N-body 的 Z：既有 440 組都是 0.02，先跑 3 組 Z=0.0144 量敏感度再決定。
3. #4 消光係數＋A_V 偏高 3–4 倍：最可能動到 headline 的一項，要先量化再決定是否重跑。
4. #12 星團縱深：跟 f_bin／dav 簡併，影響量要先用注入回收量出來。
5. #5 觀測化步驟：N-body 路線要產出科學數字之前必須做。
