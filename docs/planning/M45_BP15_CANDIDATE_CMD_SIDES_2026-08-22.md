# M45 BP15 候選星在 CMD 的紅／藍位置

日期：2026-08-22  
狀態：**完成候選星描述；不是 selection function 驗證**

## 問題

前一項檢查顯示，放寬 BP 訊噪比門檻至 15 可找回 16 顆 HR23 候選星，
但它們的顏色誤差較大。本項再問：這些星只集中在 CMD 的紅側或藍側嗎？

## 做法

對每一顆候選星，選取現有 CMD 中 `G` 星等相差不超過 0.25 mag 的星，
以這群鄰近星的 BP−RP 中位數當作局部參考。這是一個資料描述工具，
不是等時線擬合，也沒有把現有 CMD 當成無偏真值。

## 已驗證結果

- 局部中位數紅側：10/16 顆；藍側：6/16 顆。
- 顏色偏移大於各自 1σ 近似顏色誤差：10/16 顆。
- 比局部樣本第 90 百分位更紅：4 顆。
- 比局部樣本第 10 百分位更藍：3 顆。
- 整體顏色殘差中位數：+0.032 mag；範圍 −0.178 至 +0.506 mag。

所以這 16 顆**不是只往單一方向偏移**：紅、藍兩側都有明顯尾端；但樣本中
紅側稍多，而且最極端的偏移出現在紅側。這強化了下一步必須分開驗證暗端
紅／藍 selection 的理由，不能只看整體回收率。

## 不能從這裡推論的事

- 不能說紅側或藍側的星一定是污染星或真正成員。
- 不能說 BP15 會讓 IMF 變陡或變平。
- 現有 CMD 本身包含未解析雙星與可能殘留的污染，不是純單星主序。
- 最暗候選附近可比較的現有星較少，因此逐星百分位只適合當篩檢指標。

## 決策

BP15/3σ 仍只是一個待測候選。正式重建 selection 時，必須預先保留
`G≥17` 的紅側與藍側兩個驗證欄位；只要任一側失敗，就不能進入 IMF／前向模型。

## 可重現材料

- 逐星結果：`results/hr23_bp15_candidate_cmd_sides.json`
